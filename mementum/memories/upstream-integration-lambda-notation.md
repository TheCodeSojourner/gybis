Preserve nucleus lambda notation when integrating upstream artifacts into gybis

When an upstream integration artifact already follows the repo’s nucleus lambda pattern, keep the update in that same notation. Do not rewrite it into prose or markdown tables just because the upstream source is more narrative or easier to read in plain text.

This repo intentionally curates upstream material into the project’s canonical lambda syntax, so the integrated artifact should remain consistent with the surrounding skill and reference files. The pattern is part of the repository’s operational language, not just formatting.
